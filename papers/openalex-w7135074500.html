Partitioning-free 3D-IC Floorplanning

本文是对发表于 2026 年的论文《Partitioning-free 3D-IC Floorplanning》（无预划分的 3D-IC 布局规划，简称 GREAT3D）的详细深度解析。本文提出了一种用于三维集成电路（3D-IC）的新型布局规划框架，其核心贡献在于直接在原生 3D 空间中联合优化系统级架构延迟与物理互连线长。

1. 研究背景与系统全貌 (Introduction & Preliminaries)

系统背景： 在现代芯片设计中，集成电路的物理实现通常始于“网表（Netlist）”，即由前端逻辑综合产生的一组宏模块（Macro Block，具有特定电路功能和面积的逻辑单元）以及连接它们的线网（Net）。在物理设计的“布局规划（Floorplanning）”阶段，EDA（电子设计自动化）工具需要决定这些模块在硅片上的具体物理坐标，这直接决定了后续走线的长度和芯片的最高运行频率。 随着摩尔定律在二维（2D）平面的微缩放缓，长距离布线延迟已成为系统性能的最大瓶颈。3D-IC 通过将芯片垂直堆叠来缓解这一问题。本文具体聚焦于一种先进的堆叠技术：面对面（Face-to-Face, F2F）混合键合。该技术将预先制造好的两层裸片（Die）在顶层金属层面对面对齐并直接键合，无需穿透硅基底的 TSV（硅通孔），从而提供了极高密度、极低寄生效应的垂直互连。

核心问题与挑战： 在 3D-IC 的布局规划中，工具不仅要计算模块在单个平面内的 2D 坐标，还必须决定层分配（Die Assignment）——即把每个模块放在上层 Die 还是下层 Die。F2F 键合引入了一个跨层约束：同层模块通过常规金属走线通信，而跨层模块需通过键合界面通信，这导致了非均匀的通信延迟和极具挑战的 3D 物理约束。 现有的 3D 布局规划方法主要陷入两难境地：

  1. 先划分再布局（Partitioning-first）： 依赖图划分算法（如 FM 或谱聚类）先将网表硬性分割为两部分并分配给上下层，然后再独立进行 2D 布局。这种方法过早地固化了模块的层归属，切断了跨层互连与物理位置的联合优化空间，往往导致较差的线长和通信延迟。
  2. 3D 原生扩展（3D-native extensions）： 将传统的 2D 拓扑表示（如分组序列对 Grouped Sequence Pair 或 3D 切片树 3D Slicing Trees）直接扩展到 z 轴。这会引发解空间沿垂直维度的组合爆炸，工具只能使用极慢的元启发式算法进行盲目搜索，且很难在数学目标中显式地控制系统级跨层通信延迟。

本文解决方案： 为打破上述困境，本文提出了 GREAT3D，一个“无预划分（Partitioning-free）”的原生 3D 解析布局框架。所谓“无预划分”，是指该框架抛弃了前置的网表图切割步骤，而是直接接收完整的模块级网表，在单一且连续的数学优化流中同时决定模块的 3D 物理位置和层分配。

2. 架构-EDA 跨层接口与数学建模 (Problem Formulation)

本文最突出的贡献在于建立了一套清晰的“体系结构—EDA 协同”跨层接口。作者将体系结构层面用于评估处理器性能的 CPI（Cycles Per Instruction，每指令周期数） 指标，通过代理目标和连续松弛转化为了物理布局中可被连续求导优化的代价矩阵。

首先明确系统的物理输入与约束定义：

  • 网表与模块：输入模块集合 Vb={b1,…,bn}（n 为模块总数，无量纲；bi 代表第 i 个模块，索引 i 取值范围为 1…n），固定引脚集合 Vp={p1,…,pm}（m 为固定引脚总数，无量纲；pi 代表第 i 个引脚），以及线网集合 E={e1,…,ek}（k 为线网总数，无量纲；ei 代表第 i 个线网）。对于任意模块 bi，已知其宽度 wi、高度 hi、面积 ai（原文未说明具体单位）。若模块为软模块（形状可调但面积固定），其长宽比受限于上下界 rimin≤wi/hi≤rimax（无量纲，其中上标 min 和 max 分别代表长宽比的下界和上界）。
  • 硬件约束：布局必须限制在给定宽度 W 和高度 H（原文未说明具体单位）的 Die 轮廓内；模块之间仅允许存在极小的重叠容差 ϵoverlap（原文未说明具体单位，代表面积，下标 overlap 代表重叠）。工艺限制方面，F2F 键合界面的垂直跨层互连密度不得超过 ρmax（原文未说明具体单位，代表单位面积内的最大互连数，下标 max 代表最大值）。

联合目标函数的跨层推导： 作者引入了一个源自前人架构研究的广义 CPI 延迟模型，作为连接系统性能与物理布局的桥梁：

ℋ(S,L,MP)=CPIsta+α1·(latppi−latsta)
  • ℋ(·)：基于当前布局计算的 CPI 延迟代价项（原文未说明具体单位）。
  • S：系统连通性结构矩阵，大小为 n×n（无量纲）。由公式 S=∑pNp 聚合而成，其中 Np 为单线网连通性矩阵（per-net connectivity matrix），p 为线网索引。元素 Sij（无量纲）代表模块 i 和 j 之间固有的网表通信强度（输入已知参数）。
  • L：成对延迟矩阵，大小为 n×n（原文未说明具体单位）。元素 Lij（原文未说明具体单位）代表布局器确定的模块 i 到 j 之间的实际物理通信延迟，是随布局结果变化的系统响应量。
  • MP：代表 microarchitectural parameters（微架构参数，原文未说明具体单位），用于捕获缓存缺失惩罚等系统级特征（输入已知参数）。
  • CPIsta：静态基准 CPI（原文未说明具体单位），下标 sta 代表 static baseline term（静态基准项）。作者将其建模为 α2·MP+β1。
  • latppi：与布局相关的互连延迟总和（原文未说明具体单位），下标 ppi 代表 original architecture-level notation for the i-th package product（第 i 个封装产品的原始架构级符号）。计算为结构矩阵与延迟矩阵的 Frobenius 内积 ⟨S,L⟩=∑i,jSijLij。
  • latsta：静态基准互连延迟（原文未说明具体单位），下标 sta 代表 static baseline term（静态基准项）。
  • α1,α2,β1：α1 为比例系数，α2,β1 为模型参数（原文未说明具体单位）。

传统的 EDA 布局以最小化线长为主要目标，而此处的架构目标是最小化 CPI。为了协同两者，作者构造了如下联合最小化目标：

minΘℱ=(1−μ)·𝒲(E)+μ·ℋ(S,L,MP)
  • Θ：包含了所有 n 个模块的 3D 坐标和离散层分配决策的优化变量集（无单一单位）。
  • ℱ：系统的总代价目标值（复合单位，原文未说明）。
  • μ：用户设定的平衡系数，μ∈[0,1]（无量纲），控制物理线长与架构延迟在目标中的比重。
  • 𝒲(E)：传统的半周线长（HPWL）估计代价（原文未说明具体单位，实验部分报告为 μm）。

由于直接优化包含离散决策和非线性的 HPWL 非常困难，作者通过“平方欧氏距离”作为连续代理空间，将问题转化为一个加权距离匹配问题。他们将单纯的网表连接矩阵元素 Aijo（无量纲，仅反映拓扑连接，上标 o 代表 original connection matrix 即原始连接矩阵）与包含了成对延迟代价 λij（原文未说明具体单位，吸收了架构参数后，由布局距离到延迟的转换权重）的矩阵结合，定义了统一的融合连接矩阵 A：

Aij=(1−μ)·Aijo+μ·Sij·λij
  • Aij：融合连接矩阵 A 的元素（原文未说明具体单位），代表模块 i 和 j 在最终优化中的综合吸引力。通信越密、延迟越敏感的模块对，其权重被显著放大。

最终，复杂的 3D 架构-EDA 协同问题被抽象为一个紧凑的二次内积形式：

ℱ=∑i,jAij·dij=⟨A,D⟩
  • dij：模块 i 和 j 在连续 3D 空间中的平方欧氏距离代理（原文未说明具体单位，代表长度平方，作为优化的代理决策变量）。
  • D：代理距离平方矩阵，大小为 n×n（原文未说明具体单位，代表长度平方），元素 Dij=dij。

3. GREAT3D 三阶段优化方法 (Methodology)

为了求解上述连续抽象问题并生成合法的两层 F2F 布局，GREAT3D 抛弃了预划分流，采用了一个从连续到离散再到连续的三阶段优化流水线。

阶段一：3D SDP 全局优化 (3D SDP Optimization)

本阶段的目标是在一个无边界约束的连续三维空间中，利用半正定规划（SDP）将强相关的模块聚集在一起。 目标等价于寻找一个 n×3 的坐标矩阵 X∈ℝn×3（原文未说明具体单位，代表长度，包含所有模块的软坐标），在此定义 Gram 矩阵 G=XX⊤（维度 n×n，原文未说明具体单位，代表长度平方），因此距离平方项可以写为 dij=Gii+Gjj−2Gij（Gii,Gjj,Gij 均为矩阵 G 的元素，代表长度平方）。目标函数随之写为：

⟨A,D⟩=∑i=1n∑j=1nAij(Gii+Gjj−2Gij)

为了使问题转化为凸优化，作者构造了一个正半定块矩阵 Z∈𝕊+3+n（复合单位，其中下标 + 代表正半定，上标 3+n 代表矩阵维度），其内部集成了 3×3 的单位矩阵 I3×3（无量纲）、X、X⊤ 和 Gram 块 Gn×n（下标 n×n 代表矩阵维度，原文未说明具体单位）。通过一系列解析的交替子问题（利用固定方向矩阵 W* 约束秩，无量纲，上标 * 代表 current value obtained from the W-subproblem 即从 W-子问题获得的当前值；受正则化参数 α 控制，无量纲），求得松弛解。这一阶段还施加了软非重叠约束：Dij≥(ri+rj)2，其中 ri,rj 为模块 i,j 的等效半径（原文未说明具体单位，代表长度）。 为什么这么做（物理意义）： SDP 求解后的特征向量恢复出的连续 3D 坐标虽然不能直接用于光刻，但其 z 轴坐标（即 Z 顺序）蕴含了极其宝贵的“全局 Die 亲和力”——被 CPI 目标和拓扑紧密相连的模块，其求得的连续 z 坐标会自然相近。

阶段二：基于动态规划的层分配 (DP-based Die Assignment)

现在需要将上一步软分布在连续 z 轴上的模块，切分到离散的顶层和底层 Die 上（Top/Bottom）。传统的切分（如直接按模块数量取中位数）会遭遇“面积失衡”（由于模块物理面积异构，可能导致一层撑爆一层极空）以及“盲目拆分”（切断恰好处于中位线上的强连通集群）的致命问题。 作者设计了 Algorithm 1，利用动态规划在保持 SDP 诱导的 z 序连贯性的前提下，搜索一段连续区间来分配底 Die，使得两层 Die 的面积尽可能平均：

(s*,e*)=\argmin1≤s≤e≤n|∑k=seAr[k]−T|
  • s,e：候选分配区间的起始和结束索引（均为 1 到 n 之间的整数，无量纲）。
  • s*,e*：使得分配结果最接近面积平衡目标的最优起止索引（无量纲，上标 * 代表最优值，即 globally area-optimal interval）。
  • Ar[k]：按 z 轴从小到大排序后的第 k 个模块的物理面积（原文未说明具体单位，代表面积）。
  • T：理论单层 Die 的目标分配面积（原文未说明具体单位，代表面积）。计算公式为 T=(∑i=1nAr[i])·w/2（背景补充：其中 w 为均匀白边分数 uniform whitespace fraction，无量纲；除以 2 是由于物理硬件明确由两层 Die 共同分担面积）。
  • ∑k=seAr[k]：该连续区间内分配给 Bottom Die 的实际模块总面积。

核心逻辑： 这种基于前缀和在 O(n2) 内完成的面积最优子序列扫描，既没有随意交换模块破坏 SDP 阶段精心算出的跨层延迟连贯结构（因为保持了 z 序列不乱），又满足了硬性的物理面积平衡约束，是实现“无预划分”落地的关键转折。

阶段三：2D 连续微调 (2D Refinement)

分配完 Die 后，分别在两块独立 Die 内，模块初始继承的是第一阶段投影下来的 2D 连续坐标。本阶段调用 L-BFGS-B（一种能有效处理边界约束的拟牛顿法）来解开重叠并满足芯片固定轮廓约束。 优化目标定为带软惩罚的线长组合方程：

f(𝐱)=∑i<jAij·ϕ(𝐱i,𝐱j)+βfpen(𝐱)
  • f(𝐱)：2D 微调目标函数（复合单位，原文未说明）。
  • 𝐱i,𝐱j：分别表示模块 i 和 j 在单层 Die 平面内的 2D 物理坐标向量（原文未说明具体单位，代表长度，由 3D 坐标 X* 投影而来）。
  • ϕ(𝐱i,𝐱j)：混合空间距离函数（原文未说明具体单位，代表长度），定义为 α3‖𝐱i−𝐱j‖1+(1−α3)‖𝐱i−𝐱j‖2，其中范数混合比例 α3∈[0,1]（无量纲）允许算法交替使用曼哈顿距离和欧氏距离梯度，帮助搜索跳出局部极小值。
  • fpen(𝐱)：软间距惩罚项（原文未说明具体单位，代表长度平方，下标 pen 代表 penalty 即惩罚），定义为 ∑i<j[max(0,dijmin−‖𝐱i−𝐱j‖2)]2。
  • dijmin：防重叠的安全中心间距阈值（原文未说明具体单位，代表长度，上标 min 代表 minimum 即最小），本文取为模块的等效半径之和 ri+rj。
  • β：惩罚系数（原文未说明具体单位，随着迭代逐渐增大，强制挤开重叠模块）。

通过计算梯度并用 Armijo 线搜索更新步长，模块在这个“受限盒子”里被平滑排开，产生无重叠且具有优异线长的合法局部物理 2D 版图。

5. 总结与局限性 (Conclusion)

贯穿全文的主线逻辑： 传统方法在面临 3D-IC F2F 键合时，总是将“要把模块放哪层”和“要把模块放层里哪个位置”剥离开来或者用蛮力搜索，这直接导致了架构层面对互连延迟（CPI）的要求无法有效传递到物理层。本文 GREAT3D 的成功之处在于：建立了一座数学的桥梁（融合连接矩阵元素 Aij），把复杂的架构指标拍平成为了 SDP 空间中模块间的“引力”；在将连续空间拍扁到两块分立硅片这一步时，极具创造性地用基于 z 排序的 DP 区间截取代替图划分，成功保住了前面算出的核心关联路径不被打碎，又达成了面积均衡，最终交出了一份从线长到 CPI 再到拥塞度全方位占优的布局答案。

关键假设与局限性提醒： 需要注意的是，本文的结论有其不可过度推广的前提：

  1. 层数的限定：算法阶段二中 DP 寻找的是“一个”连续区间分配给底部 Die，而另一个区间给顶部 Die，且面积目标 T 是除以 2 的。这强烈依赖于“双层 Die（Two-tier stack）”的硬件设定假设。若要拓展至三层或更多异构层，必须在 DP 中搜索多切点，这将显著改变算法的实现形式与复杂度。
  2. 细粒度键合约束被抽象：本文的 3D 原生模型将 F2F 键合约束抽象为一个全局面积极限常数 ρmax（公式 7）。作者明确声明，更细粒度的微凸块（Bump/Pad）局部指派、排列以及可能引发的局部过热拥挤，被交给了下游更底层的布线验证来解决，因而在宏观布局阶段可能存在微量的信息损失。
  3. 热感知缺失：3D-IC 中致命的纵向散热问题并未被包括在内。作者在总结中明确表示，热感知（Thermal-aware）需要作为另一个附加代价项引入目标函数中，这是留给未来的单独问题。不应假定当前框架产生的布局天然能够避免局部热点。
